# Task Manager (PyQt6)

Небольшое desktop-приложение для создания задач. Окно построено на `QMainWindow`, интерфейс собран из Qt Widgets и layouts.

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Как пользоваться

1. Введите название задачи в поле **Task**.
2. При желании напишите описание в поле **Description** (можно в несколько строк).
3. Выберите один приоритет: Low, Medium или High (по умолчанию Medium).
4. Отметьте нужные настройки: Important, Send notification, Add to favorites.
5. Нажмите **Create task**. Задача появится в списке в нижней части окна и будет выведена в консоль.

Если название пустое, задача не создаётся, а в статусе появляется подсказка.

## Кнопки

- **Create task** – создаёт задачу из данных формы.
- **Clear** – очищает форму (приоритет возвращается к Medium, галочки снимаются).
- **Delete last task** – удаляет последнюю созданную задачу.

## Дополнительный блок

- Статус внизу окна: `Status: Ready` меняется на `Status: Task created` после создания задачи.
- Счётчик задач: `Created tasks: N`.
- Результат отображается внутри окна, а не только в консоли.
- Задачи хранятся в списке Python (`self.tasks`), каждая задача – словарь.
- Фильтр `QComboBox` (All / Low / Medium / High) – показывает в списке только задачи нужного приоритета. Счётчик при этом показывает общее количество задач.

## Какие виджеты и layouts использованы

| Что нужно | Widget / layout |
| --- | --- |
| Главное окно | `QMainWindow` + `QWidget` как central widget |
| Название задачи | `QLabel` + `QLineEdit` (короткий однострочный ввод) |
| Описание | `QTextEdit` (многострочный текст) |
| Приоритет | `QRadioButton` + `QButtonGroup` (можно выбрать только один вариант) |
| Дополнительные настройки | `QCheckBox` (настройки независимы друг от друга) |
| Кнопки | `QPushButton`, сигнал `clicked` |
| Фильтр | `QComboBox` |
| Вывод задач | `QTextEdit` в режиме `readOnly` |
| Основная структура | `QVBoxLayout` |
| Строки с кнопками, приоритетом и фильтром | `QHBoxLayout` |
| Название и описание (подпись + поле) | `QGridLayout` |

Layout ставится на центральный виджет (`setCentralWidget`), а не на само `QMainWindow`.
