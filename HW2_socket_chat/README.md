Что есть вообще в коде:
Заголовок сообщения состоит из 8 байт COMMAND и 4 байт LENGTH.
COMMAND дополняется нулевыми байтами до 8 байт.
LENGTH хранится как unsigned 32-bit integer в network byte order.
После заголовка передаётся PAYLOAD длиной LENGTH байт.

Комманды, которые поддерживаются: JOIN, TEXT, LIST, QUIT, ERROR.
Максимальный размер payload - 10 MB.
Сервер использует отдельный thread для каждого клиента.
